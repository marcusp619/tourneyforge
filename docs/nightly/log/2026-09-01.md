### What changed

- **`packages/db/src/seed.ts`** — `buildSeedTournaments(now = Date.now())` returns three
  tournaments as offsets from the supplied clock: `open` (starts +21d, deadline +14d),
  `active` (started 2h ago, ends in 6h, day-of registration open until lines out),
  `draft` (+90d). The two scoring formats now carry pinned uuids for the primary tenant,
  and every tournament references one of them; other tenants keep database-generated
  ids. `seed()` runs only when `seed.ts` is the process entrypoint, so importing the
  fixtures cannot issue a `DELETE`.
- **`scripts/check-seed.ts`** (new) — imports the fixtures from `seed.ts` and asserts
  values, not spelling: every `registrationDeadline > Date.now()`; at least one `open`
  and one `active`; every `scoringFormatId` non-null **and resolving to a format the
  seed actually creates** (a dangling uuid is as useless as a null); and that advancing
  the clock by a year moves every date by a year. Exits non-zero with a per-failure
  list. Contacts no database — `postgres()` is lazy, so a dummy `DATABASE_URL` suffices,
  the same trick `packages/api/test/setup.ts` documents.
- **`packages/db/src/simulate-leaderboard.ts`** — read the target tournament name from
  the seed instead of the duplicated literal `"Spring Bass Classic 2026"`, which the
  rename would otherwise have broken silently.

`import.meta.main` would be the idiomatic entrypoint guard, but `packages/db` typechecks
as CommonJS (`module: NodeNext`, no `"type": "module"`) and tsc rejects `import.meta`
with TS1470. Verified, then used `basename(process.argv[1])` instead.

## The significant find: subdomain routing was dead

`resolveTenant()` read `req.nextUrl.hostname`, which is the server's **bind address**,
not the request host. The dev script runs `next dev --hostname 0.0.0.0`, so a probe gave:

```
hostname: "0.0.0.0"                   <- what the middleware compared
host:     "midwest-bass.localhost"    <- the actual request
```

Every `.localhost` and `.{rootDomain}` comparison fell through. The tenant rewrite never
fired, every tenant page 404'd, and the Redis custom-domain lookup was dead for the same
reason. This is the product's entire multi-tenant story, and it is the kind of thing
"Phase 1 ✅ COMPLETE" was hiding. Fixed in `bd71194`, verified live:

- `midwest-bass.localhost/` → "Midwest Bass Trail"
- `midwest-bass.localhost/tournaments` → Spring Bass Classic, Lake Oahe Shootout
- `carolina-kayak.localhost/` → "Carolina Kayak Fishing" (tenants isolated)
- `localhost/` → marketing page, no tenant leak
